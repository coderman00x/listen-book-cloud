# 听书宝（listen_book）· 产品需求文档（简单 PRD）

> 版本：v1.0 ｜ 作者：许清楚（Xu）· 产品经理 ｜ 语言：简体中文

## 1. 项目信息

| 项 | 内容 |
| --- | --- |
| 项目名 | `listen_book` |
| 形态 | 本地网页应用（前后端均运行于用户本机，浏览器打开使用） |
| 前端 | Vite + React + MUI + Tailwind CSS |
| 后端 | Python + FastAPI + edge-tts |
| 原始需求复述 | 导入下载的 txt 电子书后自动生成配音 mp3，支持 app 内听书；语速、音色可调；删除时不影响本地原始文件 |

## 2. 产品目标

**一句话定位**：把本地 txt 电子书一键转为可离线收听的 AI 配音音频，安全、可调、不打扰原始文件。

**成功指标（可量化）**：

| 指标 | 目标 |
| --- | --- |
| 导入成功率 | ≥ 99%（成功读取 txt 并触发生成） |
| 生成失败率 | < 5%（含网络/edge-tts 异常） |
| 生成耗时 | 单本 ≤ 10 万字应在 3 分钟内（受网络与 edge-tts 速率影响，仅作体验参考） |
| 播放器操作响应 | 播放/暂停/拖动 < 200ms |
| 原始文件安全 | 0 起误删/误改/移动用户原始 txt（硬性红线） |

## 3. 用户故事

1. **作为导入者**，我想一次拖入多个 txt 文件，系统自动排队生成配音，这样我无需手动逐个处理。
2. **作为听书者**，我想在书架里点开一本书直接播放，并拖动进度、调节倍速，这样能按自己节奏听书。
3. **作为挑剔的听书者**，我想在生成前或设置里选择不同中文音色（如晓晓/晓伊/云扬），这样听感更顺耳。
4. **作为语速敏感用户**，我想调快或调慢语速（生成阶段或播放阶段），这样能提升信息密度或理解度。
5. **作为谨慎的用户**，我想删除某本书只清掉 app 内的音频与记录、绝不动我的原始 txt，这样用得安心。

## 4. 需求池

### 优先级说明
- **P0（Must have）**：MVP 核心，缺失则产品不可用。
- **P1（Should have）**：重要体验项，首版尽量包含。
- **P2（Nice to have）**：增强项，可后续迭代。

### P0 — 核心功能

| 编号 | 描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| TXT-001 | txt 导入（单文件 / 多文件），仅读取不修改 | P0 | 支持点击选择+拖拽；可一次导入多个 txt；导入过程对原始文件无任何写/删/移动操作 |
| TTS-001 | 导入后自动触发 edge-tts 生成 mp3 | P0 | 导入成功即自动入队生成；生成文件落于 app 数据目录；生成内容为用户可读的语音 mp3 |
| LIB-001 | 书架 / 列表展示已导入书籍 | P0 | 列表展示书名、状态（待生成/生成中/已完成/失败）；已完成书可点击进入播放 |
| VOI-001 | 音色（voice）可选，至少覆盖中文多音色 | P0 | 提供中文音色选项（如 `zh-CN-XiaoxiaoNeural`、`XiaoyiNeural`、`YunyangNeural` 等）；音色可在设置中预设、在生成时生效 |
| PLY-001 | app 内播放器：播放 / 暂停 / 进度拖动 | P0 | 可播放已生成 mp3；支持暂停与从任意进度跳转播放；进度条实时更新 |
| DEL-001 | 删除仅删 app 数据，不影响原始文件 | P0 | 删除书籍仅移除 app 数据目录中的副本与元数据；原始 txt 始终保留且不被触碰 |
| STA-001 | 生成进度 / 状态展示 | P0 | 书架卡片显示生成中进度（百分比/状态）；全局可查看当前队列状态 |
| RET-001 | 生成失败重试 | P0 | 失败书籍显示「重试」按钮；点击后重新触发生成，不改变原始文件 |

### P1 — 重要体验

| 编号 | 描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| SPD-001 | 语速可调（生成阶段与/或播放阶段） | P1 | 支持设置语速（如 0.5x–2x）；若在生成阶段设置，则影响 mp3 本身；若仅播放阶段则不影响文件，二者至少实现其一并明确标注 |
| PLY-002 | 播放倍速（0.5x/1x/1.25x/1.5x/2x） | P1 | 播放器提供倍速切换，切换即时生效且不影响已生成音频文件 |
| SET-001 | 设置面板（默认音色 / 默认语速） | P1 | 提供设置页持久化默认音色与语速，新导入书籍默认套用 |
| QUE-001 | 多文件批量排队生成 | P1 | 多文件导入时按顺序/有限并发排队生成，界面清晰展示队列与每本状态 |

### P2 — 增强项

| 编号 | 描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| CHP-001 | 长文本分章 | P2 | 按空行/章节标题切分，支持章节级跳转播放 |
| FMT-001 | 支持 epub / pdf 等其他格式 | P2 | 可导入 epub/pdf 并转换为文本后生成音频（需另行确认解析方案） |
| CAC-001 | 音频缓存与清理策略 | P2 | 提供缓存占用展示与一键清理，且不误删原始文件 |

## 5. UI 设计稿（组件树 + 布局）

### 组件树
```
AppShell (整体布局)
├── AppBar                // 标题 + [设置]入口
├── ImportZone            // 导入区：选择文件 / 拖拽，支持多文件
├── Bookshelf             // 书架列表
│   └── BookCard[]        // 书名 / 状态 / 进度条 / 操作(播放·删除·重试)
├── PlayerDrawer          // 底部常驻播放器抽屉
│   ├── PlayControls      // 播放 / 暂停 / 进度拖动
│   └── SpeedControl      // 倍速切换
├── SettingsPanel         // 设置：默认音色、默认语速
└── Toast/Notification    // 状态与错误提示
```

### ASCII 布局
```
+------------------------------------------------------+
|  AppBar: 听书宝                          [设置 ⚙]    |
+------------------------------------------------------+
|  导入区: [选择TXT文件]  或 拖拽多个 .txt 到此处        |
+------------------------------------------------------+
|  书架列表                                             |
|  +--------------------+  +--------------------+      |
|  | 书名A   已完成      |  | 书名B   生成中 62%  |      |
|  | [▶播放] [删除]      |  | [重试]  [删除]      |      |
|  | ▓▓▓▓▓▓▓░░░          |  | ▓▓░░░░░░░░          |      |
|  +--------------------+  +--------------------+      |
+------------------------------------------------------+
|  播放器抽屉 (底部常驻)                                |
|  ▶ 书名A | 进度 =====o====== | [0.5x 1x 1.5x 2x]      |
+------------------------------------------------------+
```

- **导入区**：一次可添加多个 txt，即时显示已加入队列数量。
- **书架列表**：卡片化展示每本书状态与进度；失败态高亮并提供重试。
- **播放器抽屉**：全局常驻于底部，随播放状态收缩/展开，支持倍速。
- **设置面板**：抽屉或独立页，预设默认音色与语速，保存即生效。

## 6. 待确认问题

1. **长文本分章**：是否需要在 v1 支持按章节切分与章节跳转？（影响播放器设计与生成逻辑）
2. **批量并发生成策略**：多文件导入时，采用顺序生成还是有限并发？并发上限多少以避免 edge-tts 限流？
3. **格式范围**：v1 是否仅支持 txt？epub/pdf 是否纳入本期或后续迭代？
4. **语速生效阶段**：语速优先在「生成阶段」内置于 mp3，还是仅「播放阶段」变速？二者体验与存储成本不同，需定调。
5. **音频缓存策略**：app 数据目录的清理/占用管理策略如何设计？是否提供手动清理入口？
6. **元数据范围**：除书名/状态外，是否需要作者、导入时间、字数、封面等字段？
7. **网络异常处理**：edge-tts 调用需联网，离线或弱网下的提示与重试机制细节待定。
